# 1. 주요 기능

### 1. 카테고리 및 개수 선택 화면

- 사용자가 원하는 단어 카테고리와 개수를 선택.

### 2. ChatGPT API를 활용한 단어 데이터 가져오기

- 선택한 카테고리와 개수를 바탕으로 ChatGPT에서 단어 리스트 요청.
- 단어 데이터는 24시간 동안 저장 및 활용.

### 3. 랜덤 단어 퀴즈 기능

- 영어 단어가 나오면 한글 입력, 한글 뜻이 나오면 영어 입력.
- 정답 여부 판별 및 점수 시스템.

### 4. 로컬 저장 및 제한된 데이터 유지

- 24시간 동안 단어 유지 후 새로운 단어 요청 가능.

# 2. 프로젝트 생성

- Minimum SDK: Android 8.0 (Oreo)

# 3. 주요 기능 구성

### 1. 메인 화면 (카테고리 & 개수 선택)

- 사용자가 원하는 단어 카테고리와 개수 선택

### 2. 단어 데이터 가져오기 (ChatGPT API 연동)

- OpenAI API를 활용해 영어 단어 리스트 가져오기
- JSON 파싱 및 로컬 데이터 저장 (SharedPreferences 또는 Room DB)

### 3. 퀴즈 화면 (랜덤 단어 퀴즈)

- 영어 → 한글, 한글 → 영어 랜덤 출제
- 정답 입력 후 맞으면 "정답!", 틀리면 "오답!" 표시

### 4. 데이터 저장 & 관리

- 24시간마다 새로운 단어 요청 가능하도록 데이터 관리

# 4. 개발 단계

1. UI 만들기 - activity_main.xml, QuizActivity.java 등 레이아웃 구성
2. API 요청 구현 - OpenAI API 활용해 단어 리스트 가져오기
3. 데이터 저장 - Room DB 또는 SharedPreferences 활용
4. 퀴즈 로직 구현 - 랜덤 출제 및 정답 판별
5. 앱 완성 & 테스트
